# Semaine 4 — Corrections

Les corrections E01 à E03 montrent les étapes successives du projet cumulatif
`S04E01E03_Restaurant_Qualite`.

Chaque étape conserve l’assemblage manuel accessible avec l’argument
`--manuel` dans le projet Terminal et l’assemblage par défaut avec le conteneur
.NET. Chaque état conserve aussi les comportements et les méthodes de test des
étapes précédentes. Les tests d’interaction avec la notification sont présentés
avec une doublure manuelle, puis avec Moq.
