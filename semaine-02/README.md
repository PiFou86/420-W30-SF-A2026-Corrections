# Corrections de la semaine 2

Ce répertoire contient quatre états de correction :

- `E01_Validation_Environnement` : mini-solution créée pour vérifier Visual
  Studio, xUnit, une référence de projet et Moq;
- `E02_Tests_Sans_Dépendance` : tests directs du modèle Restaurant;
- `E03_Simulacre_Manuel` : état cumulatif qui ajoute le simulacre écrit à la
  main;
- `E04_Moq` : état cumulatif final qui ajoute les tests avec Moq.

Les répertoires E02 à E04 sont volontairement cumulatifs afin de montrer l'état
attendu après chaque exercice.
